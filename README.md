# Smart Learning VR

Futuristic educational web application prototype built with React, Tailwind CSS, Vite, and Three.js.

## Features

- Futuristic login screen
- Student dashboard
- Subject selection cards
- Interactive Three.js solar system simulation
- AI assistant sidebar chatbot
- Quiz section with scoring
- Learning progress analytics
- Responsive glassmorphism UI

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://127.0.0.1:5173`.

## Build

```bash
npm run build
```
